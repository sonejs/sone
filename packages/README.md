# packages

npm workspace. The TypeScript engine — today published as
[`sone`](https://www.npmjs.com/package/sone) from
[seanghay/sone](https://github.com/seanghay/sone) — moves in here as
`packages/sone`, alongside the native Node binding.

Until then this directory is a placeholder, and the TypeScript engine stays the
behavioural reference that `fixtures/` is generated from. See
`tools/sync-fixtures.sh`.
