# sone

A declarative canvas layout engine with rich international text — flexbox
layout, Skia rendering, and PNG / JPEG / WebP / PDF / SVG output.

```rust
use sone::prelude::*;

font("Inter", "fonts/Inter-Regular.ttf")?;

let root = column()
    .gap(20)
    .padding(20)
    .size(420, 300)
    .bg("khaki")
    .corner_radius(28)
    .child(column().flex(1).corner_radius(20).corner_smoothing(0.7).bg("white"))
    .child(
        row()
            .gap(10)
            .child(column().bg("lightgreen").square(50).corner_radius(14))
            .child(column().bg("salmon").height(50).corner_radius(14).flex(1)),
    );

render(root).density(2).save("card.png")?;
```

This is the engine's own crate, not a binding. There is no FFI in the path, no
IR string to parse and no marshalling: the builder produces `sone_core::ir::Node`
directly and rendering hands it straight to Skia.

## The shape of the API

**Owned `self`, so a chain is a chain.** Every setter takes and returns `Self`,
which is what makes the tree read as one expression.

**One type per node type.** `Column`, `Row`, `Text` and the rest are distinct
structs, so the compiler keeps them apart — which is why `Text::size` can be the
**font** size while `Column::size` is the box. Every other binding had to
resolve that collision by hand; here it never arises. A `Text` is still a box,
so `width` and `height` are on it too.

The shared properties are generated by macros — `impl_layout_props!(Column, Row,
…)` — the same answer Ruby's class macros and C#'s generic extensions gave,
because Rust has no inheritance either.

**Numbers are whatever number you have.** A `Num` trait means `.gap(20)` and
`.gap(20.0)` both compile, and `Dim` takes a bare number for the common case:

```rust
.width(100)                 // Dim::Px
.min_width(Dim::Percent(50.0))
.max_width(Dim::Auto)
```

No string parsing. `"50%"` is a JavaScript affordance; Rust has an enum.

**Keywords are the IR's own enums**, re-exported from the prelude:
`JustifyContent::SpaceBetween`, `TextAlign::Justify`, `ScaleType::Cover`.

**Generated children are an iterator**, which is the whole answer:

```rust
table().children(
    records.iter().map(|record| {
        table_row().children(record.cells.iter().map(|cell| table_cell().child(text(cell))))
    }),
)
```

`maybe_child(Option<_>)` covers the conditional case.

**An explicit null is an `Option`.** A decoration colour distinguishes "unset"
from "use the text colour", so the setter takes the `Option` rather than
defaulting it:

```rust
.underline(1).underline_color(None::<String>)   // use the text colour
.underline(1).underline_color(Some("salmon"))
```

**`props` is the escape hatch** for anything not yet modelled:

```rust
.props(|props| props.tag = Some("hero".into()))
```

## One name that moved

`bullets()` rather than `list()` — `list` reads as a collection everywhere else
in Rust. `svg_path()` keeps the `svg_` prefix for symmetry with the other
bindings, where `Path` was taken.

## Engine and output

```rust
let engine = Engine::new("assets");
engine.register_font(FAMILY, std::fs::read("Inter-Regular.ttf")?)?;
engine.register_image("logo", png_bytes);        // reachable as asset:logo

let rendering = render(root)
    .engine(&engine)
    .width(816)
    .page_height(1056)
    .header(text("Page {pageNumber} of {totalPages}"));

rendering.pdf()?;                                 // selectable text, one page per break
rendering.pages()?;                               // one raster image per page
rendering.save("report.pdf")?;
rendering.layout()?;                              // the computed layout tree
rendering.metadata(Granularity::Word)?;
rendering.to_json_pretty();                       // the IR itself
```

Skia carries no system fonts, so at least one family must be registered before
any text renders. An unregistered family **falls back rather than failing**, so
a typo in a family name is a visual bug, not a caught one.

Header and footer text uses the literal tokens `{pageNumber}` and
`{totalPages}`; the engine substitutes them during pagination.

**One engine per thread.** Skia's font collection is shared inside an engine, so
every call takes the lock. Give each thread its own `Engine` for parallelism.

## Features

`render` is on by default and pulls in Skia. Turn it off to build and serialize
documents with no rasterizer at all:

```toml
sone = { version = "0.1", default-features = false }
```

## Development

```bash
cargo test -p sone
```

35 tests, including the parity gate every sone binding owes: the same document
rendered through this crate and through `sone-cli` must come out byte for byte
identical.
